# Diabetes Prediction

## Problem Statement
To predict whether the female is diabetic or not on the basis of given factors such as glucose level, BMI, etc.

## About the Dataset
- Source: Kaggle
- Total Samples: 768
- Features: 6
- Target:
  - 0 → Non-Diabetic
  - 1 → Diabetic

## Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- Google Colab

## Models Used

Support Vector Machine (SVM)

## Methadology

1. Diabetes Data Collection
2. Feature & Label Separation
3. Data Standardization
4. Splitting the dataset into training and testing parts
5. Model Evaluation
6. Forming Predictive System

## Results
- Accuracy on Training data: 78.6%
- Accuracy on Test data: 77.2%
